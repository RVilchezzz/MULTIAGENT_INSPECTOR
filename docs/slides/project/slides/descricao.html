Real MMAD example (MVTec AD bottle, question and answer from mmad.json). Accuracy: Jiang et al., ICLR 2025; official MMAD leaderboard, Oct 2026.

This is exactly what the system receives: one photo of a good part (the reference), the part to inspect, and multiple-choice questions. This bottle has 5 questions in MMAD: is there a defect, which type, where, what it looks like, and its effect. When a production line switches products there is no time or data to train a detector, only one good photo. MLLMs (multimodal large language models, LLMs that also see images) can do this from instructions, but they are still 13 points below expert inspectors. The hypothesis is measurable: we compare against the best single model and against voting with the same number of calls.
