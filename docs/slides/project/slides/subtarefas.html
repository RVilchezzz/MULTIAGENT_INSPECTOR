Every image comes with several of these questions, already answered in mmad.json. The figure shows one example per subtask with the correct option highlighted. Discrimination is yes or no; everything else has four options, so random guessing gives 50% and 25%. Models do well on object questions and poorly on defect questions, which is where a visual expert should help most. The official metric is accuracy per subtask and the simple mean of the seven.
