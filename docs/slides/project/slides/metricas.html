Error analysis: 100 failures of S labeled as perception, reasoning, orchestration (MAST taxonomy) or annotation error.

The baselines are designed to rule out easy explanations. B1 is the best single open model. B3 gives that same model the same number of calls as our system and takes a majority vote, so if S wins it is not just more compute. B4 votes two different models without the expert or verifier, to isolate the value of diversity. Then the ablations remove one agent at a time. McNemar is a paired test: it compares, question by question, where one system is right and the other wrong. Besides accuracy we report the inspection errors that matter in a factory and the cost per image.
