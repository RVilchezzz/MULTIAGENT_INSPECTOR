Images from MMAD: MVTec AD and MVTec LOCO (CC BY-NC-SA 4.0), VisA (CC BY 4.0), GoodsAD (research use). Defect descriptions from mmad.json.

These are real MMAD pairs, exactly as the strict protocol gives them: the reference is always the first random normal template of that category. Defects range from obvious (a broken bottle) to tiny (a chip on one of four candles) to logical (a label that should be there and is not, which does not look like a stain at all). The bottom box is an important catch we found while preparing these slides: in MVTec LOCO and GoodsAD the single reference can be another product variant, so a naive pixel or patch comparison flags the whole object. That is why the readers and the verifier matter, and why we break results down by source.
